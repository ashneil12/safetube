# SafeTube parent controls

References captured from the existing SafeTube UI before implementation:

- `setup-presets.png`: retain the readable preset cards, plain descriptions and teal selection. Reuse these rules in the hub; add rather than replacing a parent's own text.
- `rules.png`: retain rounded white cards, dark heading, quiet helper copy and text areas. Add Only show and context using those same controls.
- `lists.png`: retain video thumbnail/title rows and explicit Allow/Undo buttons. Make details an additional clear action, with the decision and available metadata together.

Purpose: parents need to understand uncertain blocks, refine filtering, and choose fail-closed backup behavior from setup or the hub. Existing Bricolage/DM Sans, teal accents, dark buttons, pale background, 24px card padding and rounded outlines remain the visual system. The detail dialog must show an honest metadata gap and route YouTube viewing through the PIN-protected native bridge. Safety failure is a whole-page wall with parent access and retry, including when previously allowed content exists.
